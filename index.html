部署步骤

发表于 2026-09-12 分类于 技术

1. Hexo 主页更新

发布到 671111733.github.io

  1. 写markdown文件放到 blog/source/_posts

  2. hexo s 预览

    http://localhost:4000/

  3. hexo cl && hexo g && hexo d

    cgd三部曲发布

2. 非主页更新

mtnghost库，不显示在主页；671111733.github.io/mtnghost

  1. html页面放在mtnghost根目录

  2. git add . 改动存进暂存区

  3. git commit -m “说明” 提交到本地仓库

  4. git push 页面推送到远程

    完整版 git push origin main

备用：

git status 查当前仓库状态

git pull 拉取远程仓库内容

其他

bash操作快捷键：ctrl+insert 复制；shift+insert 粘贴
